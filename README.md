## 🖥️ Run Locally

```bash
# 1. Clone the repo
git clone https://github.com/Prajjwal2507/personal-site.git
cd personal-site

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env
# Fill in RESEND_API_KEY, CONTACT_TO_EMAIL, CONTACT_FROM_EMAIL

# 4. Start the dev server
npm run dev
# → http://localhost:5173
```

> **Note:** The contact form requires a [Resend](https://resend.com) API key. All other sections work without any env vars.

### Environment Variables

| Variable | Description |
|---|---|
| `RESEND_API_KEY` | Get a free key at [resend.com/api-keys](https://resend.com/api-keys) |
| `CONTACT_TO_EMAIL` | Your email address for form submissions |
| `CONTACT_FROM_EMAIL` | Verified Resend sender (e.g. `onboarding@resend.dev` for testing) |
